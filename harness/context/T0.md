# T0 — 基座契约（2026-10-31）

- 边界：默认离线；不自动加载 `.env`；平台凭证仅环境输入；配置文件为显式 TOML。
- 配置优先级：CLI > 进程环境 > TOML > 默认值；Token 使用 SecretStr，不回显验证输入。

- 测试：配置优先级、缺失/空凭证、HTTP 放行、非法 URL、脱敏、预算、CLI。
- 验证：Python 3.12.11，uv.lock；13 tests，100% branch coverage；ruff/mypy/CLI 均通过。
