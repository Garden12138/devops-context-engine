# T5 — Application Services / CLI 契约（2026-11-01）

- CLI 提供 doctor/init/discover/catalog/trace/mapping/bug/pipeline/stack；默认离线，JSON envelope，table 可选。
- CLI/MCP 共用 AppServices；所有平台调用均显式 live + read_only；扫描需 Scope，查询需受控资源 ID。
- 本地 init 写 Catalog；普通查询只读 Catalog，Bug 图片写私有缓存不写平台。
- Bug fixture 仍经 ZenTao adapter + MockTransport 认证下载两张真正合成 PNG，不能仅伪造路径。
- Bug 摘要含业务 ID、模块候选/状态/证据、受控附件、版本、不确定性；不强行确认映射。
- Pipeline 只读诊断，区分 Buildx 前置错误与 make 缺失；原始 trace 先脱敏再限长。
- Stack 输出三种快照摘要/漂移与 stale，不把 Status 当健康，不把相同 tag 当版本一致。
- 配置/验证/SQLite/输入错误固定诊断，JSON 非交互退出码 2；stdout 仅结果，日志 stderr。
- 测试先覆盖 CLI 全命令帮助/核心流程/分页/退出码/表格/预算，真实 subprocess smoke 与服务契约。
