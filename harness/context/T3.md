# T3 — Catalog 契约（2026-10-31）

- SQLAlchemy 2 + SQLite；Alembic 版本迁移；本地私有目录，数据库外键与事务。
- Entity 按来源实例/类型/外部 ID 唯一；Edge 按两端/关系唯一；Snapshot/Evidence 按版本内容幂等。
- 完整批次原子导入；ScanRun 记录 running/complete/failed、scope、错误码与摘要，不存原始响应。
- Entity/Edge 内容变化生成历史；最近验证时间刷新；相同内容不增版本。
- 扫描仅更新观测状态；人工确认/拒绝独立保留，冲突或来源消失单独标记，不改审核结论。
- 范围消失只影响同一 scope 成员；其他 scope 活跃成员保护共享资源。
- 查询有页大小/深度上限，双向 trace；软删除保留历史与审核审计。
- T3 提供受控本地 review 存储 API 以测试保护逻辑；T4 承担规则与人工审核用例校验，MCP 不暴露该 API。
- 测试先定义迁移、重复导入、版本、scope 删除、审核保护/撤销、外键失败原子性、双向查询与限制。
